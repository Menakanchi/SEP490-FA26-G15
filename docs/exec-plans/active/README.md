# Exec plan đang chạy

Mỗi việc nhiều bước (nhiều PR, nhiều ngày, hoặc giao cho agent chạy dài) có một file
ở đây **trước khi** bắt đầu: mục tiêu, phạm vi, các bước, tiêu chí xong, và nhật ký
quyết định cập nhật dần. Xong thì chuyển sang [`../completed/`](../completed/2026-09-30-vehicsim-mvp-loop.md)
kèm phần *Kiểm chứng* (lệnh đã chạy và số đo được).

Quyết định kiến trúc vẫn phải thành ADR ([`docs/adr/`](../../adr/README.md)); exec
plan chỉ link tới ADR, không thay ADR. Owner và deadline theo ngày nằm ở GitHub
Issues/Project.
